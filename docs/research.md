# Research: what the top elementary-math apps do, and what Number Quest borrows

Researched September 2026. Only *ideas and mechanics* were borrowed — no code, art, names, or content from any product.

## Apps reviewed

| App | Model | What it does well | Limits / criticisms |
|-----|-------|-------------------|---------------------|
| **Prodigy Math** | Free-to-play RPG; 100M+ users, grades 1–8 | Deep gamification: XP and levels, currency spent on gear/cosmetics, quests, badges, progress bars, daily streaks, avatar customization; difficulty adapts and requires mastery before moving on | Reviewers call it a *practice* tool — it does not teach; instruction must come from elsewhere. Paid membership pressure. Leaderboards used "with discretion" because they discourage some kids |
| **Khan Academy Kids / Moose Math** | Free, ad-free, ages 2–8 | Warm mascot characters, short activities, city-building rewards, multiple users per device, offline | Stops at early elementary; no written algorithms |
| **SplashLearn** | Subscription, PreK–5, 8,000+ games | Adaptive difficulty, detailed parent progress reports, multiple child profiles | **Second child profile requires a paid plan** ($7.99–11.99/mo) — the exact problem this project solves |
| **IXL** | Subscription, K–12 | Very fine-grained skill tree, adaptive practice, diagnostics | Worksheet-like; per-child pricing |
| **DreamBox** | Subscription, K–8 | Adaptive lessons with intelligent scaffolding, strong reporting | $12.95/student/mo; heavily conceptual/"visual model" approach rather than standard algorithms |
| **Reflex Math / XtraMath** | Fact-fluency tools | Short, frequent, timed retrieval practice; fact families; track speed and accuracy per fact; adaptive scheduling of weak facts | Timed pressure described by some parents as stressful/boring; speed-only focus |
| **Monster Math / Todo Math** | Kids' game apps | Missions, unlockable characters, collectible badges, daily streaks, *short sessions*, immediate feedback | Limited scope; subscriptions |

Sources: CodaKid "Top 22 Math Apps of 2026", Kidslox, Brighterly, SpellingJoy K-5 roundup, trophy.so Prodigy gamification case study, OpenEd Prodigy review, Modulo Reflex review, Prodigy's own fluency-tool comparison, Educational App Store Monster Math review, SplashLearn support pages, Common Sense Education (archived reviews).

## Design decisions taken from the research

1. **Teach, don't just drill** (fixing Prodigy's biggest criticism). Every lesson opens with Learn slides, and column-method lessons include *animated worked examples* generated by the same step engine the kid later uses — so the demo and the practice match exactly.
2. **Traditional scope and sequence** (Saxon/Abeka-style): counting → facts to 20 → place value → column addition with carrying → column subtraction with borrowing (including across zeros) → times tables → 2-digit×1-digit with carrying → long multiplication with partial products → division facts → long division (Divide, Multiply, Subtract, Bring down). Vertical notation with crossed-out digits and small carried numbers, exactly as written on paper.
3. **Gamification layer** (Prodigy, Monster Math): XP + levels, coins, a sticker shop and unlockable themes to spend them on, badges, daily goal, streaks, world/lesson path with stars, confetti and sound feedback. The learning content is the game — problems are never hidden behind a separate mini-game the child can grind.
4. **Fact fluency done gently** (Reflex/XtraMath, minus the stress): every basic fact answered is tracked (right/wrong/speed). Missed facts are quietly re-served more often inside practice. Timing lives *only* in the optional Arcade, which is framed as a game with scores, combos and a family leaderboard rather than a test.
5. **Multiple profiles, free** (the SplashLearn gap): unlimited players, each with fully separate progress, on one shared server so any computer in the house sees the same players.
6. **Parent reporting** (SplashLearn, DreamBox, IXL): per-child dashboard with lessons, stars, accuracy, time, per-world completion, and a "facts to work on" list.
7. **Leaderboards used with care** (Prodigy's note): family-only, per drill, opt-in by playing the Arcade; lessons themselves never rank kids against each other.
8. **Short sessions** (Monster Math): lessons are 5–10 quiz problems (3–4 for long written problems); Arcade rounds are 60 seconds.
